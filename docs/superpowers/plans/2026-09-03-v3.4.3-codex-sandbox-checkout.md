# v3.4.3 Codex Sandbox-Checkout Implementation Plan

> **For agentic workers:** this plan is executed by Compound V (`/v:dispatch`) on Engine C — one job per task below. Task A runs on the **codex** backend (`compound-v-run-codex-worker.sh`, its own worktree); the review runs on Claude/Opus.

**Goal:** a bash helper that builds a byte-identical sandbox checkout for hook probes, produced by a Codex worker inside the pipeline, gated and merged like any other job.

**Architecture:** one implement job (codex, worktree, standard tier) + one review job (claude, direct). No new state; the launcher contract (`skills/backend-launcher/adapter-codex.md`) is the mechanism under test.

**Tech Stack:** bash 3.2, git; `tests/*.sh` sandbox.

## Global Constraints

- Bash 3.2 compatible (macOS default), `set -eu`, shellcheck-clean; git only — no python, no jq.
- Never writes outside `<dest>`; refuses a non-empty `<dest>`; exit 0 on success, non-zero with one message on any fault.
- Spec: `docs/superpowers/specs/2026-09-03-v3.4.3-codex-sandbox-checkout-design.md` (read it first).

### Task A: the helper and its test (codex)

**Files:** `scripts/compound-v-sandbox-checkout.sh` (new), `tests/test-sandbox-checkout.sh` (new).

**Interfaces:**
- Produces: `compound-v-sandbox-checkout.sh <dest> [--keep-execution] [--empty-pre-eval] [--taxonomy-from <path>]` → prints `sandbox: <dest>` and `files: <n> commit: <sha>`; exit 0. Refusals: not a git repo (exit 2), dest exists and is non-empty (exit 3).
- Consumes: `git ls-files -z` of the repository the script is run in (its cwd or `$PWD`).

- [ ] **Step 1: the failing test** — `tests/test-sandbox-checkout.sh`: create a tiny repo (`a.txt`, `docs/superpowers/execution/x/state.json`, `docs/superpowers/pre-eval/r.json`, an untracked `junk.txt`, an executable `run.sh`); run the helper to `$T/sb`; assert: `a.txt` byte-identical and `run.sh` still executable, `junk.txt` absent, `docs/superpowers/execution/` absent (present with `--keep-execution`), `docs/superpowers/pre-eval/` empty with `--empty-pre-eval`, `git -C $T/sb log --oneline | wc -l` == 1, a second run into the same non-empty dest exits 3 with a message, a run outside a git repo exits 2. Expected before Step 2: the script does not exist → FAIL.
- [ ] **Step 2:** implement the script (`git ls-files -z | while IFS= read -r -d '' f; do mkdir -p …; cp -p …; done` — `cp -p` keeps modes; `git init -q` + `git -c user.email=… -c user.name=… commit -q -m sandbox`; drop/keep/empty per flags; `--taxonomy-from` copies one file over `.claude/compound-v-impact-taxonomy.yaml`).
- [ ] **Step 3:** `bash tests/test-sandbox-checkout.sh` green; `shellcheck scripts/compound-v-sandbox-checkout.sh` clean.
