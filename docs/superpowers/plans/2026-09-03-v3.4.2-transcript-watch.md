# v3.4.2 Transcript Play-ahead Implementation Plan

> **For agentic workers:** this plan is executed by Compound V (`/v:dispatch`) on Engine C — one job per task below, disjoint lanes, the gate and the authority after every wave.

**Goal:** a read-only script that reads live workflow transcripts and reports out-of-lane writes, wrong cwd, errors, denials and stalls per job, minutes before the gate records them; wired into `/v:status --live` and `/v:dispatch`'s advice.

**Architecture:** two disjoint jobs in one wave (A: the script + its test; B: the two command docs + CHANGELOG/versions), then the review job. No new state field; discovery by scanning transcripts for the run directory path.

**Tech Stack:** Python 3.9 stdlib, `tests/*.sh` sandbox, the scope gate's matcher imported by path.

## Global Constraints

- Python 3.9 stdlib only; the script never writes into the run directory or the repository; exit 0 on every advisory path.
- The path matcher is imported from `scripts/compound-v-scope-check.py` by path (one matcher, never two).
- No fabricated metrics; timings in docs are measured or absent.
- Spec: `docs/superpowers/specs/2026-09-03-v3.4.2-transcript-watch-design.md` (read it first).
