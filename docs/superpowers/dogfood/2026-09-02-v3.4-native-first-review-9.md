#### 4 — **LOW · PASS 2** · `hooks/lane-guard.sh:382-384` still states the pre-H2 behaviour as current

Fifteen lines above the code that implements H2, the comment block says:


#### 5 — **LOW · PASS 2** · a timed-out probe leaks its grandchild

`_cv_bounded` (`hooks/lane-guard.sh:352-366`) runs `"$@" … &` and the watchdog does
`kill -9 "$_pid"`. `$_pid` is the *wrapper* the candidate path resolves to; a wrapper that has
already `exec`'d or forked leaves its child alive. Observed in my H3 run: after the hook returned
in 0.99 s, `pgrep -fl "sleep 30"` still listed the sleeping grandchild. The hook itself is correctly
bounded — this costs nothing in latency — but on a machine whose interpreter genuinely hangs, every
`Write`/`Edit`/`Bash` call leaves one orphan behind for the hang's full duration. → Kill the process
group (`kill -9 -- -"$_pid"` under `set -m`, or equivalent) rather than the pid.

#### 6 — **LOW · PASS 2** · the pre-3.4.0 compat path is switched by a scope-exempt file

`read_sealed_patch` (`compound-v-emit-workflow.py:3033-3043`) and `sealed_patch_faults`
(`compound-v-integration-gate.py:519-527`) both treat a gate document with **no** `patch_sha256` as
pre-sealing: "no artifact is required and none is trusted", and the finalizer "falls back to the old
fresh-diff merge". The switch is one JSON key in `receipts/<id>.gate.json` — which finding 2 shows
is **exempt by name** from the scope gate and writable by a direct-mode worker. That is the shape
this project recorded as a rule after v3.3.6: *never keep a compat path that widens an
authorization*.

I tried to exploit it and **could not**: deleting `patch_sha256` and then reverting the worktree
still reads as `forged`, because the receipt's independent `diff_digest` binding catches the moved
tree — authority `forged`, `integration: refused`, finalize rc 1, nothing committed, worktree not
pruned. So this is a residual, not a live hole, and I am reporting it as one. → Either drop the
compat branch (no pre-3.4.0 receipt can reach a 3.4.0 finalizer in a run this pipeline emitted), or
gate it on something a worker cannot write.
