# Dogfood — the tier finally reaches `agent()`

**Run:** `docs/superpowers/execution/2026-09-02-v3.0.5-model-routing/`
**Date:** 2026-09-02 · **Engine C**, one wave, two jobs, `routing_stance: balanced`

## What was being tested

Not "does dispatch work" — 3.0.4 settled that. This run tests one claim: **a job that
declares only a `tier` and no `model` is spawned on the model that tier names.**

Neither job carries a `model`. `exec-lane` is `tier: standard`, `judge-lane` is
`tier: deep`. If the wire is real they run on two different models; before 3.0.5 both
would have inherited whatever the session was running, which in practice was always Opus.

## What happened

| Job | Tier | Resolved | `model_source` | Verdict |
|---|---|---|---|---|
| `exec-lane` | `standard` | `sonnet` | `tier` | success |
| `judge-lane` | `deep` | `opus` | `tier` | success |
| Gate ×2, Record ×2, Finalize ×1 | *(transport)* | `sonnet` | `light` cell | — |

Both lanes gated clean and the wave finalizer merged them into a single commit,
`b21e827`. Seven agents, zero errors.

Six of those seven ran on Sonnet: the execution lane plus all five transport agents.
One ran on Opus: the judgment lane. Under 3.0.4 all seven would have been Opus.

**This is a count, not a saving.** The run measured no cost and no duration, and this
document claims neither. What it establishes is that the routing decision now reaches
the runtime — the thing that was untrue for the entire life of the tier vocabulary.

## Before probing, a probe

`opts.model` was verified against the live runtime before any of this was built: a
three-agent workflow spawning `sonnet`, `opus` and `fable`, each clamped to a single
`echo`. All three returned. Fable is not assumed to be reachable from a workflow agent —
it was checked, because this repo has been wrong before about what a runtime accepts.

## What this run does not show

* **One wave, two jobs, no `depends_on`.** Escalation on re-attempt is covered by
  selftests, not by this run: nothing here failed, so nothing here escalated.
* **`frontier` was not exercised live.** No job in this run asked for Fable. The tier
  resolves and the runtime accepts the value; that is two separate facts and only the
  second was probed end-to-end.
* **No conservative-stance run.** The stance is now passed to the resolver, and its
  selftests pin every cell, but only `balanced` ran here.
