**Escalation predicates (answer to "which predicates detect auth/sessions/payments/PII/new endpoints/forms by content").** None. `postdiff-reclassify` has no built-in predicate for any of them (a grep for password/payment/cookie/route/endpoint/form/pii finds nothing). What it does: (1) path hits against the project taxonomy's `sensitive_path_list` (:660-667); (2) size: tracked lines from `git diff --numstat` plus bounded untracked reads, cap 50 lines / 20000 bytes; (3) binary / deleted / symlink-escape fail closed; (4) `taxonomy.match_content` over hunk lines, where `CONTENT_KINDS` is only `legal_copy, i18n_placeholder, feature_flag, config_literal, shared_token, a11y` (taxonomy.py:152-155) and the patterns come from the project's own YAML; (5) a Python AST pass comparing function signatures and a normalised control-flow fingerprint (`_py_fingerprints`, :391); (6) JS/TS/Go/Ruby changes fail closed (`_FAILCLOSED_CODE_EXTS`, :152) unless an injected parser passes. So the spec's content predicates are NEW code; reusable pieces are the bounded git/numstat/fail-closed harness and the AST fingerprint, not the vocabulary. It also takes the tier as an input (`--from-decision`), matching the spec's "recomputed after every fix against the pinned base".

**Refuse-once mechanism (epic-goal-stop.sh).** Four layers. (1) Registration `"<script>" || true`; (2) `trap 'exit 0' EXIT` is the first executable line (:116), all logic in `hook_main` whose stdout is discarded unless it returns 0 (:683-687); no `set -e/-u`. (3) A block is only ever JSON `{decision:"block", reason, systemMessage}` on stdout (:529, :613), never an exit code. (4) The once-ness is a marker file `$TMPDIR/compound-v-stop-hook/triage-<sha256(project|session_id)>` created with `: >"$marker"` BEFORE the block is printed (:501; the bypass rule's twin at :585); at entry `[ -e "$marker" ] && return 1` (:396, :553). `stop_hook_active` is read and logged but deliberately not used to return (:393 comment, :652-653). Consequences for v4: the marker is per session, not per run — a second run in the same session is never refused; it lives in the OS temp dir, so a temp sweep re-arms it ("at most once while the marker survives"). Event gate first: only `hook_event_name == "Stop"` (SubagentStop shares the session id and would eat the marker, :640). Git work is bounded by `_bounded_capture` polling (budget `COMPOUND_V_TRIAGE_GATE_BUDGET_MS` default 800, :170-237); an unfinished check is recorded to `triage-incomplete-<key>` and fails open. `tests/test-epic-goal-stop.sh` (578) asserts `|| true` is present and that a broken script really exits non-zero.

**run-band: cost, quota, stage.** Stage is `run.phase` from `compound-v-dashboard.py hud` (state.json), polled every 5 s only when the mtime moved (run-band.tsx:50-54, :248). Quota is the only budget signal: `$.session.usage().rateLimits` (:118) giving `five_hour`/`seven_day`/`spend_limit` percent used, diffed against a baseline kept in `$.store` per run id (:125-141). There is no cost in dollars or tokens anywhere in the band; the `Quota` type is percent only (types/index.d.ts). The state atom is keyed `plugin: 'superpowers-v'` (:11-12; also `types/index.d.ts` `PluginState`, asserted by `tests/test-run-band-mod.sh`: `state writes: superpowers-v.band`). Needs Claude Code >= 2.1.287.

## 3. Triage hook — what to keep for light/full

Constants: `_MAX_ATTEMPTS=3` (scoring attempts per session, :216), `_MAX_DIRECT=6` (DIRECT decisions per session, :218), `_REQUEST_MAX_CHARS=4000`. Early exits, all kept-worthy and cheap (~9 ms): not `UserPromptSubmit`; slash command; short question (<=200 chars ending `?`); short read instruction (<=80 chars starting read / show me / explain / summarize / look at / cat, single clause); no session id; "tiny" closed greeting list (:578: hi hello hey yo ok okay k thanks thank you thx ty yes yep no nope sure cool great nice got it good perfect done + Russian привет спасибо ок окей да нет понял отлично хорошо …); per-session `nudged-<key>` marker; `attempt-<key>` and `direct-<key>` counters (length of file in bytes = count). "Set up" test is `docs/superpowers/` dir OR `.claude/compound-v.json` (:646) — one setup-notice per session otherwise. The tier is decided by `compound-v-preeval.py triage` (3-axis bands -> DIRECT/SCOPED/FULL via a 3x3 matrix, taxonomy + `compound-v-localize.py` + optional T3 headless classify); the hook only prints it. For v4: keep the filters, markers, counters, setup test (retargeted to `docs/compound-v/` / config); replace the engine call with a small light/full rule plus "unclassifiable = full"; drop pre-eval records, outcomes stream, active-run check, T3 classify (and its `timeout: 25`; the plain hook needs 10).

## 6. Salon usage measurer `~/Dev/cv-salon-e2e-kit/session-usage.py` (68 lines)

`session-usage.py <projects-subdir> <session-uuid>` or `--latest <repo-path>`. The project directory slug is `abspath` with `/` and `.` replaced by `-` (verified: `-Users-oleg-Dev-superpowers-v` exists). It reads `<projdir>/<sid>.jsonl` plus `glob(<projdir>/<sid>/**/*.jsonl)` — real subagent transcripts live at `<sid>/subagents/agent-*.jsonl` (verified on a local session). Each assistant message is counted once, keyed by `message.id` globally across files (fallback `(uuid, file)`); only messages with a `usage` block count; output is JSON `{session, transcripts, wall_clock_s, per_model{messages,input,cache_write,cache_read,output}}`. It ran against this session. **It reports tokens only, never dollars.** The salon dollar figures came from `claude -p --output-format json` -> `total_cost_usd` in `turn.sh:27-28`. The spec's "$7 CLI cost" with "cost measured from transcripts" therefore needs a price table (a source and a date) or the CLI's own figure; `<synthetic>` rows appear and must be ignored; `--latest` picks the newest main transcript by mtime, which is wrong when two sessions run in one repo.
