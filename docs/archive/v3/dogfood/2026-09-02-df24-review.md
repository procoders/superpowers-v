### The finding this run was built to catch

`spec-reviewer` is the one agent Engine C spawns by role, and the run's premise
(`spec.md`) is that 3.3.3's Step 0 was verified by selftests and an index diff,
never by watching an agent do it. Watched end to end, **it does not happen.** The
role-spawn hands the reviewer a bash clamp that admits exactly one command form,
and Step 0 is not it. The recall instruction is prose in an agent definition; the
clamp is mechanism. Mechanism wins — this is the repo's own
"prose vs mechanism" lesson landing on the feature meant to demonstrate recall.

Worth noting: a reviewer less careful about provenance would have written
"V-memory returned nothing" here and passed the acceptance criterion. The gap is
invisible unless the agent distinguishes *empty result* from *never ran*.
