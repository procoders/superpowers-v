→ Move it back under finding 99 where it is true, or delete it. An unmeasured claim wearing the word "confirmed" is exactly what the anti-ruflo charter exists to stop, and it is worse in a CHANGELOG than in a comment because it outlives the person who can check it.

**5. Finding 105 ships with no CHANGELOG entry.** *(low)*

**6. `.run.lock` retirement is gated on the wrong condition at two of its three call sites.** *(low)*

`compound-v-emit-workflow.py:4430-4431` and `:4573-4574` call `_retire_run_lock(run_dir)` only `if out.get("lane_map_retired")` — that is, only if `_retire_lane_map`'s `os.remove` *returned True*. The step-1 refusal path at `:4240` calls it unconditionally. The three sites disagree, and the two gated ones inherit a failure mode from the thing they are gating on: if `lane-map.json` is already gone at the terminal transition (hand-cleaned, a `/v:resume` path, a second finalize), `_retire_lane_map` returns False and the `.run.lock` this fix exists to retire survives — which is the exact 46-stale-files state finding 105 describes. The terminal phase, not another `os.remove`'s return value, is the condition that matches the docstring ("at a TERMINAL phase transition").

The lock-ordering reasoning at both sites is correct and worth keeping: each call is outside the `with _run_dir_lock(...)` that covered the same transition, as `_retire_run_lock`'s own docstring requires. Verified at `:4215-4240` and `:4249-4293`.

**7. Three validators disagree on `timeout_s`'s domain.** *(low)*

- manifest validator: `int`, not `bool`, `1..540` (`compound-v-validate-manifest.py:2258-2268`)
- resolver: any non-bool `int|float` that is `> 0` — no upper bound, floats allowed (`compound-v-fastpath-run.py:1017-1024`)
- worker `tc_validate`: any JSON `number >= 1` — no upper bound (`compound-v-run-*-worker.sh:134`)

A manifest cannot produce a divergent value, so nothing ships broken. But a hand-built slice with `timeout_s: 0.5` passes the resolver and then hard-fails `tc_validate` as a usage fault (`exit 2`) at the worker, rather than being refused where it was produced. The resolver is the authority that writes the file; it should enforce the same integer domain the manifest does.

## Verdict

**ISSUES.** Seven, ranked:

1. `skills/compound-v/execution-manifest.md:452` and `agents/parallel-dispatcher.md:173` document "absent ⇒ 480" / "default 480"; the five workers default to 900 and the emitter passes no flag when the manifest is silent, so an external backend's real absent-case budget is 900 s.

5. Finding 105 (bookkeeping paths, `.run.lock` retirement) ships with no `[Unreleased]` entry. Not an AC failure; still a silent change to test selection.
6. `compound-v-emit-workflow.py:4430-4431` and `:4573-4574` gate `_retire_run_lock` on `_retire_lane_map`'s return value; `:4240` does not. Gate all three on the terminal phase instead, or the stale-lock state this fix removes can reappear.

Findings 1–4 are all in the same two paragraphs of `CHANGELOG.md` plus two documentation lines; 5–7 are one changelog line and two small code conditions. None touches the mechanisms the five acceptance criteria gate, every one of which was verified by live command on the merged tree. Fix the seven, and this is APPROVED.
