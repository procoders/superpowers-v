# v3.4 Native-first Implementation Plan

> **For agentic workers:** this plan is executed by Compound V (`/v:dispatch`) on Engine C — one job per task below, disjoint lanes, the git-derived scope gate after every job. Spec: [`docs/superpowers/specs/2026-09-02-v3.4-native-first-design.md`](../specs/2026-09-02-v3.4-native-first-design.md) — read it first; every acceptance criterion below is a sentence from it.

**Goal:** keep every capability, replace our copies of Claude Code mechanisms with the native ones, and remove the mechanisms that have no reader.

**Architecture:** four disjoint jobs — A (epic → `/goal`/`/loop`/`/schedule`), B (triage hook runs the scorer + attended DIRECT + ledger removal), C (dashboard `serve` removal + scorecard from results) — run in parallel in worktrees; D (shared docs, README, CHANGELOG, version) runs after them in the main tree. The spec reviewer gates DONE.

**Tech Stack:** bash hooks (shellcheck-clean, fail-open), Python 3.9 stdlib scripts with `--selftest`, `tests/*.sh` sandboxes.

## Global Constraints

- Python 3.9 stdlib only; every hook fails open; hook input is never shell-interpolated.
- No fabricated metrics; never Haiku.
- Every new subcommand names its caller in its docstring.
- Tests are rewritten in the same task that changes the behaviour they pinned; CI (`.github/workflows/validate.yml`) must stay green.
