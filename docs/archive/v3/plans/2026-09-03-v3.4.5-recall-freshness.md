### Task A — `scripts/compound-v-memory.py`
- [ ] Extract the FTS5-only body of `cmd_refresh` (tracked files → changed/removed → `reindex_file` / purge → `indexed_files` upkeep; **no** embedder) into `refresh_fts5(conn, root) -> (n_indexed, n_removed)`; `cmd_refresh` keeps its lock, `--rebuild`, `--quick` and the embedding branch and calls the helper for the FTS5 case.
- [ ] `index_staleness(conn, root)` returns `(new, changed, removed)`; move ALL callers together: `cmd_search`, the selftest (`:1286`) and `doctor` (delete its duplicate computation at `:1110-1117`).
- [ ] `refresh_fts5` stamps meta `chunker_version` itself; `cmd_refresh`'s embedding branch keeps the `changed` list it computed BEFORE calling `refresh_fts5` (or the `embedding IS NULL` union) — never a post-refresh hash diff.
- [ ] `cmd_search`: compute staleness FIRST (before any search — today it runs after, cosmetically); if the db is missing and `--no-refresh` → today's exit 1 + message unchanged; if the db is missing → create it (`open_db_checked` + schema) and fall into the refresh; if `new+changed+removed > 0` and not `args.no_refresh` → `acquire_lock`; if the lock is free, `refresh_fts5`, release, `sys.stderr.write("V-memory: refreshed %d stale doc(s) before recall (FTS5 lane)\n")`; if the lock is held, keep today's warning and search stale — silently, never refresh's "already running — skipped" line. The inline refresh never applies QUICK_MAX_CHANGED and never consults config_wants_embeddings(). Then the existing BM25/dense search unchanged.
- [ ] argparse: `--no-refresh` (dest `no_refresh`, store_true) on `search`.
- [ ] Selftest (inside the existing `--selftest` tmp-repo section): after the first `refresh`, write `docs/superpowers/specs/2026-09-03-later.md` containing the word `quokka-freshness`; `cmd_search` with a shim `no_refresh=True` → no `later.md` in results and the staleness warning on stderr; `cmd_search` with `no_refresh=False` → `later.md` found and the refresh line on stderr; a second plain search prints no refresh line (nothing stale). Capture stderr with `contextlib.redirect_stderr`; the args shim carries `repo, query, top, intent, json, no_embed, no_refresh`.
