### Task A — `scripts/compound-v-emit-workflow.py`
- [ ] JS `async function withRetry(stage, jobId, fn)`: `for (attempt = 1; attempt <= CFG.retry.max_attempts; attempt++) { let r; try { r = await fn(); } catch (e) { r = null; lastErr = String(e); } if (r !== null && r !== undefined) return { value: r, retries }; if (attempt < CFG.retry.max_attempts) { const wait = Math.min(60000, 2000 * Math.pow(2, attempt - 1)); retries.push({stage, job: jobId, attempt, wait_ms: wait}); await new Promise(res => setTimeout(res, wait)); } } return { value: null, retries, exhausted: true, last_error: lastErr }` — no Date, no Math.random (the emitter's FORBIDDEN_PATTERNS refuse them and the runtime does too).
- [ ] Wrap every `agent(...)` in implementStage, gateStage, recordStage, finalizeWave and the review path; compose AROUND implementStage's existing `isAgentTypeMissing` fallback (that fallback runs inside `fn`, not around it); each stage's null handling stays exactly as today when `exhausted`.
- [ ] Carry `retries` into the stage result (`{ ..., retries: [...] }`); Record writes them to `results/<id>.json` as `retries[]` (schema already `additionalProperties`? — check `schemas/job_result.schema.json`; if the top level is closed, put them under the existing free-form field the schema allows, or add `retries` to the schema in the same commit and note it).
- [ ] Reviewer lift: in the review path, when `exhausted` and `job.type === 'review'` and `CFG.retry.escalate_reviewer`, compute the next model with the Python-emitted `CFG.escalation` map (emit `{"sonnet":"opus","opus":"fable"}` from `CLAUDE_ESCALATION`; an explicit manifest `model` that is not on the ladder is never escalated) and spawn once more with `opts.model = next`, label `+ ' (escalated)'`; pass `--escalated-from <prev>` to gate-receipt.
- [ ] `cmd_gate_receipt`: new optional `--escalated-from` recorded on the receipt; `cmd_record` copies it into the result. On exhaustion Record's reason is `agent returned null N times (transient API failure suspected; the runtime's failure text is not visible to the script)`, `failure_class: other`.
- [ ] `CFG.retry` emitted from the manifest's `retry` block, defaults `{max_attempts: 3, escalate_reviewer: true}`.
- [ ] Selftests: emitted-script string checks (`withRetry` defined; every `await agent(` in the five stage functions is inside a `withRetry`; `setTimeout` present; no forbidden pattern); a Python mirror of the backoff table (2000, 4000, 8000 … ≤ 60000); a Record fixture with `retries` + exhaustion ⇒ `failure_class other` + the reason; gate-receipt `--escalated-from` round-trips; `--selftest` green.
