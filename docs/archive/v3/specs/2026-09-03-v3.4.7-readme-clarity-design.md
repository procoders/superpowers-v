# v3.4.7 — README that a newcomer can read in five minutes — design

**Date:** 2026-09-03 · **Decided by:** Oleg ("да делай — документация должна быть понятной и простой") after the 2026-09-03 README audit (11 findings) · **Scope:** docs, one SVG, one `/v:init` offer

## The one rule

**Clear and simple.** README.md is the front door: what it does, how to install, how to use it, what to know — in that order, in plain words, each claim true of the code in HEAD. Everything measured, historical or defensive moves to `AGENTS.md`, `CHANGELOG.md` or `TROUBLESHOOTING.md` and is linked, not repeated. Target: README.md ≤ 130 lines, no section longer than a screen, no paragraph longer than five sentences.

## What changes (from the audit)

1. **Requirements** shrinks to the floor (`Claude Code ≥ 2.1.219`), the one-line ambient cost of the lane guard ("~150–240 ms on every Write/Edit/Bash; method and numbers in AGENTS.md") and the **`worktree.baseRef: head` project setting** — a real install requirement (dependent jobs only integrate under it, finding 60) that was documented nowhere for installers. The 950-word measurement essay leaves README (it stays verbatim in AGENTS.md).
2. **How it routes the work** describes the three tiers the triage hook actually assigns — DIRECT (a trivial, unambiguous edit; one worker, then commit), SCOPED (the tests that reference what changed, not the whole suite; SCOPED+ = a small edit on a sensitive path, deep review + a cross-model second opinion), FULL (recon → three pre-flights → plan → manifest → parallel dispatch → three-pass review) — and which model does what (Opus judges and reviews; Sonnet executes junior slices and scans; Codex/others as opt-in workers or the second opinion). `docs/routing.svg` is redrawn to show exactly that and nothing else.
3. **Backends** name what the repository ships: Claude, Codex (kernel-sandboxed, preferred for untrusted work), Antigravity and Cursor (lower-trust), **opencode and Devin (experimental: adapters and workers exist, not dogfooded)**.
4. **V-memory** says it is fresh by construction (a search refreshes its own index) and that the reviewers read it before every verdict.
5. **Co-change advisory** says when it actually runs (when the partition reviewer is dispatched — `/v:dispatch`'s review step), not "before every dispatch"; a follow-up is recorded to wire it into the validator.
6. **Install**: the plugin lines, then the optional CLIs (Codex ≥ 0.143 for gpt-5.6-sol), then the `baseRef` setting with the exact JSON, then Context7. No price tags.
7. **Commands** table lists every user-facing command with one line each: `/v:init`, `/v:onboard`, `/v:epic`, `/v:dispatch`, `/v:orchestrate`, `/v:triage`, `/v:review-plan`, `/v:pr-review`, `/v:adr`, `/v:remember`, `/v:memory-refresh`, `/v:status` (`--live`), `/v:resume`, `/v:dashboard`, `/v:preferences`, `/v:models`.
8. **What runs in every session** — one small table of the registered hooks (SessionStart banner + memory refresh, UserPromptSubmit triage, PreToolUse lane guard on Write/Edit/Bash + the brainstorm nudge, PostToolUse plan nudge + memory refresh, PreCompact/PostCompact snapshot/resume, Stop triage gate) and the one line to turn the triage gate off.
9. **Verification program** keeps its link and numbers (re-read from the regenerated index footer at write time) and gains the list of the eight stages in one sentence each.
10. The Academy/cheatsheet block stays (it is the fastest way in) but moves below "How to use it".

## Acceptance criteria

1. **Clear and simple, checked mechanically:** `wc -l README.md` ≤ 130; no line over 200 characters outside code blocks and tables; no `##` section over 30 lines; the measurement essay (`Re-measured 2026-09-03`) appears in AGENTS.md and not in README.md.
2. **True of the code:** every command in the table exists under `commands/`; every backend named has an adapter under `skills/backend-launcher/`; the hook table matches `hooks/hooks.json`; the three tiers match `scripts/compound-v-preeval.py`'s `DECISION_TO_TIER`; the two index numbers equal the footer of `docs/superpowers/dogfood/README.md` in HEAD; every relative link resolves (the dead-link gate replica exits 0).
3. `docs/routing.svg` renders (valid XML, `xmllint --noout` or python `xml.etree`) and its text nodes name DIRECT, SCOPED, SCOPED+, FULL, Opus, Sonnet, Codex — and nothing about a "fast path" or an "advisor" that no longer exists.
4. `commands/v-init.md` offers the `baseRef` edit with the exact JSON and says why (dependent jobs); `TROUBLESHOOTING.md` has the entry; `lint-frontmatter` green.
5. A reader test: the reviewer, reading README.md alone, writes down the three commands a newcomer types to install and run one feature, and they are the ones the docs say.
